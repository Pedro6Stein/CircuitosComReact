# ⚡️ CircuitosComReact

**CircuitosComReact** é uma ferramenta web minimalista construída com **React 18** e **Vite** para resolver, de forma rápida e interativa, pequenos cálculos elétricos — inspiração nas demandas que enfrentei na SunLab, onde frequentemente precisava de uma solução ágil para dimensionar resistores, capacitores e circuitos básicos.

---

## 🚀 Funcionalidades

- **Simulação instantânea** de circuitos em série e paralelo  
- **Cálculo automático** de resistências equivalentes, correntes e tensões  
- **Interface interativa**: ajuste valores de componentes em tempo real  
- **Feedback visual** imediato dos resultados no browser  

---

## 🛠️ Stack Tecnológica

- **Framework:** React 18 + Vite  
- **Linguagens:** JavaScript (ES6+), HTML5, CSS3  
- **Qualidade:** ESLint, Prettier  
- **Ferramentas:** npm/yarn, Git/GitHub  

---

## ⚙️ Instalação & Execução

```bash
# 1. Clone este repositório
git clone https://github.com/Pedro6Stein/CircuitosComReact.git
cd CircuitosComReact

# 2. Instale as dependências
npm install
# ou
yarn

# 3. Inicie em modo desenvolvimento
npm run dev
# ou
yarn dev

# 4. Abra http://localhost:5173 no seu navegador
